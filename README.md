# Restaurant Chatbot

A simple command-line restaurant chatbot that responds to common customer questions in English and Swahili.

## Requirements

- Python 3

## Run

```bash
python3 main.py
```

Type a message to get a response. Type `q` to quit.

## What it can answer

- Greetings and farewells
- Restaurant services and menu questions
- Restaurant location

The chatbot uses keyword matching and does not require external packages.
